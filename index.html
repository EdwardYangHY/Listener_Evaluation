听测任务说明 / About This Listening Test

本任务旨在评估多说话人对话语音到语音翻译系统（speech-to-speech translation，S2ST）。这类系统接收一种语言的对话语音，并生成另一种语言的翻译语音。理想的输出不仅应准确传达原意，还应保留不同说话人的声音特征、表达方式，以及对话中自然的轮次交替。

This listening test evaluates multi-speaker conversational speech-to-speech translation (S2ST) systems. These systems take a spoken conversation in one language and produce translated speech in another. Ideally, the translation should convey the original meaning while preserving each speaker’s voice, expressive delivery, and the natural exchange between speakers.

本次听测包含 20 组真实双人对话片段：10 组英译中和 10 组中译英。每组提供一段源音频，以及四个匿名系统生成的翻译音频。请先听源音频，再逐一听取系统输出，按照下方说明，对六个维度分别评分。请独立评价每个系统，各系统可以获得相同分数。

The test contains 20 excerpts from real two-speaker conversations: 10 English-to-Chinese and 10 Chinese-to-English. Each sample includes the original source audio and translations produced by four anonymous systems. Listen to the source first, then evaluate each system output on the six dimensions described below. Rate each system independently; different systems may receive the same score.

评价时，请同时关注“翻译是否准确”和“听起来是否保留了原对话的声音与交流方式”。例如，一段翻译可能语义准确，但说话人声音发生变化，或轮次衔接不自然；请在对应维度分别反映这些差异。

Consider both how accurately the meaning is translated and how well the speech preserves the voices and interaction of the original conversation. For example, an output may convey the meaning correctly but change a speaker’s voice or introduce unnatural transitions. Reflect these differences in the relevant dimensions.

请在安静环境中使用耳机，并确保能够理解中文和英文。转写仅供辅助阅读，译后音频的转写由 ASR 自动生成，并非标准答案；请以实际音频为准。开始前填写评分者 ID，完成全部评分后导出 JSON 文件并发送给研究负责人；暂停时也请导出备份，网页不会自动提交结果。

Please use headphones in a quiet environment and ensure that you understand both Chinese and English. Transcripts are provided only as a reading aid. Transcripts of translated speech are generated by ASR and are not ground truth; base your judgments on the audio. How to use this page

First, type your name or ID in the “Rater ID / name” box at the top left. It is written into the exported file and is how your ratings are told apart from other raters'. A rater ID is required before rating or exporting.
  1. Rate every system in a sample, then move on with Next → or the numbered buttons at the top.
  2. The numbered buttons show your progress:
    12 grey — not started
    12 amber — started but incomplete: some ratings are still missing
    12 green — complete 12 blue — the sample you are on now
  3. Before exporting, check that no button is grey or amber. The counter next to the export buttons also shows how many samples are fully rated; the page warns you if you export while something is missing.
  4. ⚠ Export before you stop working or leave this computer — otherwise your ratings can be lost.
    Your answers are kept only inside this browser on this machine; nothing is saved to the server or a shared drive. They come back if you reopen the same link, in the same browser, on the same machine with the same rater ID — but they are gone from this browser's session if you clear browsing data or use a private window, and are not available when you switch machine or browser or open the page at a different address or port.
    So whenever you pause: click ⬇ Export JSON at the bottom, even if you are only part-way through. You can carry on later and export again — each export contains everything rated so far, so keep the newest file.
